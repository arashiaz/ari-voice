# آری‌ویس | AriVoice

نسخهٔ اولیهٔ **دستیار فرمان صوتی آفلاین اندروید**. رایگان، بدون حساب و بدون سرور؛ برنامه حتی مجوز `INTERNET` ندارد. مجوز میکروفون تنها برای شنیدن فرمان‌های یک‌باره است (شنود دائمی در پس‌زمینه وجود ندارد).

## امکانات

- گفتار فارسی و انگلیسی به متن به‌صورت محلی: **Vosk** با مدل جداگانهٔ هر زبان که کاربر وارد می‌کند؛ یا تشخیص گفتار **on-device** اندروید ۱۲+ در صورت نصب بودن بستهٔ زبان مربوط روی گوشی. هیچ‌وقت از تشخیص گفتار شبکه‌ای اندروید استفاده نمی‌شود.
- فرمان‌های فارسی و انگلیسی از جمله «باز کن [نام برنامه]»، «open [app]»، «search for [query]»، «جستجو کن [عبارت]» (بازکردن جستجو در مرورگر)، «روی [نام دکمه] بزن»، «بنویس [متن]»، «اسکرول پایین/بالا»، «برو عقب»، «خانه»، «اعلان‌ها».
- کاشی تنظیمات سریع برای گفتن فرمان از داخل سایر برنامه‌ها. فرمان‌های مربوط به صفحه بعد از بازگشت به برنامهٔ قبلی اجرا می‌شوند.
- خواندن پاسخ با صدای محلی زبان انتخابی، **فقط اگر** صدای غیرشبکه‌ای آن زبان در موتور TTS گوشی نصب باشد.
- ورودی متنی برای استفاده بدون میکروفون یا تست فرمان‌ها.

## نصب و راه‌اندازی

1. پروژه را در Android Studio (JDK 17، Android SDK 35) باز کنید و APK را بسازید. حداقل اندروید ۸ (API 26) است. دستور ساخت: `./gradlew assembleDebug`.
2. در برنامه زبان فارسی یا انگلیسی را انتخاب کنید. برای تشخیص گفتار مستقل از بسته‌های گوشی، فایل ZIP مدل Vosk **همان زبان** (مانند `vosk-model-small-fa-0.5.zip` برای فارسی و یک مدل `en` برای انگلیسی) را از [فهرست رسمی مدل‌های Vosk](https://alphacephei.com/vosk/models) با مرورگر گوشی دریافت کنید و روی «واردکردن مدل آفلاین (ZIP)» بزنید. برای زبان دوم انتخاب زبان را تغییر دهید و مدل دوم را جداگانه وارد کنید؛ مدل فارسی قبلی حفظ می‌شود. حجم مدل‌ها متفاوت است؛ ZIP در حافظهٔ خصوصی برنامه استخراج می‌شود. برای اجرا پس از این مرحله اینترنت لازم نیست. مدل در APK قرار نگرفته تا دانلود و نصب اپ سبک بماند.
3. اجازهٔ میکروفون را بدهید. برای لمس/نوشتن/اسکرول در سایر برنامه‌ها، **در صورت تمایل** سرویس دسترس‌پذیری آری‌ویس را خودتان در تنظیمات گوشی فعال کنید.
4. برای اجرا از داخل یک برنامهٔ دیگر، کاشی «فرمان صوتی آری‌ویس» را به تنظیمات سریع گوشی اضافه کنید. یک بار کاشی را لمس کنید، فرمان را بگویید و منتظر بازگشت به برنامه باشید. به‌جای کاشی می‌توان از صفحهٔ اصلی برنامه هم فرمان داد.

## مرزهای عملکرد و حریم خصوصی

این یک **مفسر فرمان‌های مشخص** است، نه یک مدل زبانی محاوره‌ای یا دستیار همه‌کاره. کنترل داخل برنامه‌ها فقط روی عناصر قابل‌دسترس صفحه عمل می‌کند؛ بعضی برنامه‌ها عناصرشان را به سرویس دسترس‌پذیری نشان نمی‌دهند. لمس فقط با نام **دقیق و یکتا** انجام می‌شود؛ فیلدهای رمز عبور تغییر داده نمی‌شوند، پیام‌ها خودکار ارسال نمی‌شوند و هیچ تراکنشی خودکار تأیید نمی‌شود. برای نوشتن باید کادر متن قابل‌ویرایش از پیش انتخاب شده باشد. اگر بستهٔ زبان انتخابی در تشخیص گفتار on-device اندروید موجود نباشد، مدل Vosk آن زبان ضروری است.

**جستجوی وب** فقط با اینترنت گوشی در مرورگر ممکن است. نسخهٔ فعلی هیچ API هوش مصنوعی آنلاین ندارد: «رایگان و بدون سرور» برای APIهای ابری عمومی تضمین‌شدنی نیست (سهمیه/کلید/سیاست سرویس‌ها تغییر می‌کند). اضافه‌کردن مدل زبانی محلی در آینده به رم و توان پردازشی بیشتر نیاز دارد. برنامه هیچ‌گونه صوت، متن یا دادهٔ صفحه را برای سرور ارسال نمی‌کند.

## توسعه

- پروژه Kotlin/Android با Vosk Android `0.3.47` است. تست‌های فرمان: `./gradlew testDebugUnitTest`.
- منطق فرمان‌ها: `CommandParser.kt`؛ واردکردن مدل: `ModelImporter.kt`؛ اقدامات صفحه: `VoiceAccessibilityService.kt`.
- انتشار در فروشگاه‌ها مستلزم بررسی سیاست‌های Accessibility و توضیح واضح استفاده از این قابلیت است.

## APK آماده از GitHub Actions

در تب **Actions** مخزن، workflow «Android APK» را باز کنید؛ پس از موفقیت اجرا، در پایین صفحهٔ همان run بخش **Artifacts**، فایل `AriVoice-debug-APK` را دانلود کنید. ZIP را از حالت فشرده خارج کنید و `app-debug.apk` را روی گوشی اندرویدی نصب کنید (در صورت نیاز، اجازهٔ «نصب از این منبع» را به فایل‌منیجر بدهید). این نسخه برای آزمایش با کلید debug امضا شده و artifact پس از ۳۰ روز منقضی می‌شود. برای ساخت دوباره می‌توان از دکمهٔ **Run workflow** روی شاخهٔ `arena/31de8a79-ari-voice` استفاده کرد. مدل‌های گفتار در APK نیستند؛ طبق راهنمای بالا، ZIP مدل‌های مورد نیاز را جداگانه وارد کنید.

**مدل‌های دیگر:** Vosk مدل *تشخیص گفتار* است، نه مدل گفت‌وگویی. برای گفت‌وگوی هوشمند آفلاین می‌توان در نسخهٔ بعد موتور اجرای GGUF (مثلاً llama.cpp) و انتخاب چند مدل کم‌حجم اضافه کرد؛ اما به فضای ذخیره‌سازی، رم و پردازندهٔ گوشی وابسته است و در این نسخه هنوز وجود ندارد. سرویس‌های رایگان هوش مصنوعی آنلاین معمولاً محدودیت سهمیه و شرایط استفاده دارند.

**اولویت توسعه:** کیفیت واقعی تشخیص گفتار و فهم فرمان روی گوشی‌های واقعی مهم‌تر از اضافه‌کردن یک LLM نمایشی است. مدل گفت‌وگویی سبک فقط پس از داشتن موتور محلی قابل اجرا و سنجش مصرف رم/سرعت به اپ اضافه می‌شود؛ هنوز بخشی از APK فعلی نیست.
