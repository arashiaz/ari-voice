# آری‌ویس | AriVoice

نسخهٔ اولیهٔ **دستیار فرمان صوتی آفلاین اندروید**. رایگان، بدون حساب و بدون سرور برای پردازش؛ مجوز `INTERNET` فقط برای دریافت اختیاری فایل‌های مدل استفاده می‌شود؛ صدا و سؤال‌ها به سرور ارسال نمی‌شوند. مجوز میکروفون تنها برای شنیدن فرمان‌های یک‌باره است (شنود دائمی در پس‌زمینه وجود ندارد).

## امکانات

- گفتار فارسی و انگلیسی به متن به‌صورت محلی: **Vosk** با مدل جداگانهٔ هر زبان که کاربر وارد می‌کند؛ یا تشخیص گفتار **on-device** اندروید ۱۲+ در صورت نصب بودن بستهٔ زبان مربوط روی گوشی. هیچ‌وقت از تشخیص گفتار شبکه‌ای اندروید استفاده نمی‌شود.
- فرمان‌های فارسی و انگلیسی از جمله «باز کن [نام برنامه]»، «open [app]»، «search for [query]»، «جستجو کن [عبارت]» (بازکردن جستجو در مرورگر)، «روی [نام دکمه] بزن»، «بنویس [متن]»، «اسکرول پایین/بالا»، «برو عقب»، «خانه»، «اعلان‌ها».
- کاشی تنظیمات سریع برای گفتن فرمان از داخل سایر برنامه‌ها. فرمان‌های مربوط به صفحه بعد از بازگشت به برنامهٔ قبلی اجرا می‌شوند.
- خواندن پاسخ با صدای محلی زبان انتخابی، **فقط اگر** صدای غیرشبکه‌ای آن زبان در موتور TTS گوشی نصب باشد.
- ورودی متنی برای استفاده بدون میکروفون یا تست فرمان‌ها.
- گفت‌وگوی محلی با مدل GGUF کوچک **Qwen2.5-0.5B-Instruct Q4_K_M** و موتور llama.cpp؛ پرسش‌های خارج از فرمان‌های مشخص به آن ارجاع می‌شوند، اما پاسخ مدل هرگز مستقیماً اقدام اندرویدی اجرا نمی‌کند. فقط برای گوشی arm64 ساخته شده است.

## نصب و راه‌اندازی

1. پروژه را در Android Studio (JDK 17، Android SDK 35) باز کنید و APK را بسازید. حداقل اندروید ۸ (API 26) است. دستور ساخت: `./gradlew assembleDebug`.
2. در اولین اجرا، راه‌اندازی گفتار آفلاین پیشنهاد می‌شود. می‌توانید همان‌جا دانلود را تأیید کنید یا زبان فارسی/انگلیسی را انتخاب کرده و روی **«دریافت مدل گفتار»** در کارت بالای صفحه بزنید. پس از دانلود گفتار، دریافت مدل هوش مصنوعی نیز با تأیید جداگانه پیشنهاد می‌شود. مدل فارسی Vosk `small-fa-0.42` حدود ۵۳ مگابایت، انگلیسی `small-en-us-0.15` حدود ۴۰ مگابایت است. برای زبان دوم آن را جداگانه دریافت کنید. اگر دانلود مستقیم مشکل داشت، ZIP را از [فهرست رسمی Vosk](https://alphacephei.com/vosk/models) با مرورگر بگیرید و با «واردکردن مدل آفلاین» انتخاب کنید.
3. اجازهٔ میکروفون را بدهید. برای لمس/نوشتن/اسکرول در سایر برنامه‌ها، **در صورت تمایل** سرویس دسترس‌پذیری آری‌ویس را خودتان در تنظیمات گوشی فعال کنید.
4. برای گفت‌وگوی آفلاین، با اتصال اینترنت اولیه و تأیید خودتان روی **«دریافت مدل هوش مصنوعی»** (حدود ۴۹۱ مگابایت) بزنید؛ یا فایل GGUF سازگار را از فایل‌منیجر وارد کنید. مدل رسمی Qwen با SHA-256 بررسی می‌شود. بارگذاری اولیه روی گوشی زمان می‌برد؛ سپس اینترنت لازم نیست.
5. برای اجرا از داخل یک برنامهٔ دیگر، کاشی «فرمان صوتی آری‌ویس» را به تنظیمات سریع گوشی اضافه کنید. یک بار کاشی را لمس کنید، فرمان را بگویید و منتظر بازگشت به برنامه باشید. به‌جای کاشی می‌توان از صفحهٔ اصلی برنامه هم فرمان داد.

## مرزهای عملکرد و حریم خصوصی

برای اقدامات گوشی از یک **مفسر فرمان‌های مشخص** و برای گفت‌وگو از یک مدل محلی سبک استفاده می‌شود؛ مدل ممکن است اشتباه کند و جایگزین دستیار همه‌کاره نیست. کنترل داخل برنامه‌ها فقط روی عناصر قابل‌دسترس صفحه عمل می‌کند؛ بعضی برنامه‌ها عناصرشان را به سرویس دسترس‌پذیری نشان نمی‌دهند. لمس فقط با نام **دقیق و یکتا** انجام می‌شود؛ فیلدهای رمز عبور تغییر داده نمی‌شوند، پیام‌ها خودکار ارسال نمی‌شوند و هیچ تراکنشی خودکار تأیید نمی‌شود. برای نوشتن باید کادر متن قابل‌ویرایش از پیش انتخاب شده باشد. اگر بستهٔ زبان انتخابی در تشخیص گفتار on-device اندروید موجود نباشد، مدل Vosk آن زبان ضروری است.

**جستجوی وب** فقط با اینترنت گوشی در مرورگر ممکن است. هیچ API هوش مصنوعی آنلاین استفاده نمی‌شود. فقط دانلود اولیهٔ مدل‌ها از alphacephei.com و huggingface.co به اینترنت نیاز دارد. برنامه هیچ صوت، متن سؤال یا دادهٔ صفحه را به این میزبان‌ها ارسال نمی‌کند. فایل GGUF حدود ۴۹۱ مگابایت است و باید در فضای خصوصی گوشی ذخیره شود. TTS فارسی به صدای *آفلاین* نصب‌شده روی گوشی وابسته است و برنامه نمی‌تواند وجود آن را تضمین کند.

## توسعه

- پروژه Kotlin/Android با Vosk Android `0.3.47` و llama.cpp پین‌شده در commit `8642541b255bfb5dc39cd351a178be09013a55d6` است. برای ساخت محلی قبل از Gradle اجرا کنید: `git clone --depth 1 --branch v0.8.0 https://github.com/ggml-org/llama.cpp.git vendor/llama.cpp` و Android NDK 27.2 + CMake 3.22.1 نصب کنید. CI این کارها را خودش انجام می‌دهد. تست‌های فرمان: تست‌های فرمان: `./gradlew testDebugUnitTest`.
- منطق فرمان‌ها: `CommandParser.kt`؛ واردکردن مدل: `ModelImporter.kt`؛ اقدامات صفحه: `VoiceAccessibilityService.kt`.
- انتشار در فروشگاه‌ها مستلزم بررسی سیاست‌های Accessibility و توضیح واضح استفاده از این قابلیت است.

## APK آماده از GitHub Actions

در تب **Actions** مخزن، workflow «Android APK» را باز کنید؛ پس از موفقیت اجرا، در پایین صفحهٔ همان run بخش **Artifacts**، فایل `AriVoice-debug-APK` را دانلود کنید. ZIP را از حالت فشرده خارج کنید و `app-debug.apk` را روی گوشی اندرویدی نصب کنید (در صورت نیاز، اجازهٔ «نصب از این منبع» را به فایل‌منیجر بدهید). این نسخه برای آزمایش با کلید debug امضا شده و artifact پس از ۳۰ روز منقضی می‌شود. برای ساخت دوباره می‌توان از دکمهٔ **Run workflow** روی شاخهٔ `arena/31de8a79-ari-voice` استفاده کرد. وزن‌های مدل‌ها داخل APK نیستند؛ با دکمه‌های دریافت در برنامه آن‌ها را یک‌بار نصب کنید. اگر نصب نسخهٔ debug جدید روی نسخهٔ قبلی خطای امضا داد، حذف نسخهٔ قبلی ضروری است و مدل‌های ذخیره‌شده در آن حذف می‌شوند.

## منابع و مجوزها

- موتور llama.cpp: مجوز MIT، کد JNI اندروید برگرفته از نمونهٔ رسمی نسخهٔ `v0.8.0` و مجوز آن در `licenses/llama.cpp.LICENSE`.
- مدل Vosk فارسی/انگلیسی: Apache 2.0؛ دانلود با رضایت کاربر از منبع رسمی.
- مدل Qwen2.5-0.5B-Instruct-GGUF: Apache 2.0؛ فایل Q4_K_M از مخزن رسمی Qwen (با SHA-256) دریافت می‌شود.

این مدل ۰٫۵ میلیاردی برای مکالمهٔ کوتاه است، نه پاسخ‌های دقیق تخصصی. اندازه‌گیری دقت صوت و سرعت تولید پاسخ روی گوشی واقعی همچنان لازم است. دانلودها فعلاً هنگام باز بودن صفحهٔ برنامه انجام می‌شوند و اگر برنامه بسته شود باید دوباره شروع شوند.
